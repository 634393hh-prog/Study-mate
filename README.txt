StudyMate v2 — تحديث التطبيق من الآيفون
1. فك ضغط الملف ZIP في تطبيق «الملفات».
2. افتح مستودع GitHub: Study-mate.
3. ارفع الملفات الثلاثة إلى جذر المستودع واستبدل القديمة: index.html وsw.js وmanifest.webmanifest.
4. اضغط Commit changes وانتظر نشر GitHub Pages.
5. افتح https://634393hh-prog.github.io/Study-mate/

الميزات: اختيار عدة ملفات في الدرس الواحد، وإضافة رابط YouTube وعرضه داخل الدرس. فيديو YouTube يحتاج الإنترنت ولا يتم تنزيله. الملفات تحفظ محلياً في المتصفح على هذا الجهاز ولا تتزامن تلقائياً مع أجهزة أخرى.
