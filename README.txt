StudyMate Offline PWA - النسخة المطوّرة

الملفات:
- index.html: التطبيق
- sw.js: التخزين للعمل دون إنترنت
- manifest.webmanifest: تعريف التطبيق
- icon-192.png و icon-512.png: الأيقونات

التحديثات:
- يمكن إرفاق عدة ملفات في الدرس الواحد.
- يمكن فتح الملفات المرفقة من بطاقة الدرس.
- يدعم الدرس رابط YouTube مع مشغل مضمّن يتطلب اتصالاً بالإنترنت.
- النسخ الاحتياطي والاستعادة يدعمان مجموعة الملفات لكل درس، مع دعم النسخ القديمة.

مهم:
- لا يوفر التطبيق تنزيل فيديوهات YouTube من الرابط. تشغيل فيديو YouTube يحتاج الإنترنت؛ لمشاهدة فيديو دون اتصال استخدم ميزة التنزيل الرسمية في تطبيق YouTube إن كانت متاحة لحسابك، أو أرفق ملف فيديو محفوظاً لديك وتملك حق استخدامه.
- يجب رفع الملفات إلى استضافة HTTPS (مثل GitHub Pages) حتى يعمل Service Worker.
- بعد تحديث الملفات على GitHub، افتح التطبيق بالإنترنت مرة واحدة لتحديث التخزين المؤقت. إذا بقيت النسخة القديمة، أغلق التطبيق وافتح رابط الموقع في Safari مع تحديث الصفحة.
